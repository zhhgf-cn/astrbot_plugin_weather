# AstrBot 天气查询插件

> 🌤️ 基于 [wttr.in](https://wttr.in) 的天气查询插件，支持实时天气、逐小时预报、多城市对比、日出日落查询，以及**灾害天气预警全群自动推送**，无需 API Key。

## ✨ 功能特性

- **实时天气**：温度、体感温度、天气状况、湿度、风向风速、气压、能见度、紫外线指数、降水量、云量
- **3 天预报**：每日最高/最低温度、天气状况、日出日落、降雨概率、紫外线指数
- **逐小时预报**：每 3 小时一个时段，含温度、降雨概率、风力等
- **多城市对比**：一次性对比 2-5 个城市的当前天气
- **日出日落**：日出日落时间、月相、月升月落
- **8 个 LLM 工具**：AI 可在对话中自主调用 8 种天气工具（每条指令都有对应工具）
- **🚨 灾害预警推送**：订阅城市后，定时检查天气，发现灾害自动全群推送
- **9 种灾害检测**：暴雨/雷暴/暴雪/冻雨/极端高温/极端低温/大风/大雾/强紫外线
- **指令直查**：支持 `/天气` 等中文指令直接查询
- **中文支持**：天气描述返回中文，支持中文城市名查询
- **全球覆盖**：支持城市名、机场代码、地标名称等查询方式
- **零配置**：无需申请任何 API Key，安装即用

## 📦 安装

在 AstrBot WebUI 的插件管理页面，输入以下仓库地址安装：

```
https://github.com/AstrBotDevs/astrbot_plugin_weather
```

或通过指令安装：

```
/plugin i https://github.com/AstrBotDevs/astrbot_plugin_weather
```

### 指令总览

| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `/天气 <城市>` | 查询当前天气 | `/天气 北京` |
| `/天气 <城市> -f` | 查询天气 + 3天预报 | `/天气 上海 -f` |
| `/天气订阅 <城市>` | 🔔 订阅灾害天气预警 | `/天气订阅 北京` |
| `/天气退订 <城市>` | 取消订阅 | `/天气退订 北京` |
| `/天气退订 全部` | 取消全部订阅 | `/天气退订 全部` |
| `/预警列表` | 查看订阅列表 | `/预警列表` |
| `/检查预警` | 🔍 立即检查预警 | `/检查预警` |
| `/天气` | 查看帮助 | `/天气` |

别名指令：`天气`/`查天气`/`天气查询`、`天气订阅`/`订阅天气`/`天气预警订阅`、`天气退订`/`取消天气`/`天气预警退订`、`预警列表`/`天气预警`/`订阅列表`、`检查预警`/`天气检查`/`预警检查`

### AI 工具方式

安装后插件自动注册 **8 个 LLM 工具**，AI 会根据用户提问自主选择调用。每条指令都有对应的 LLM 工具：

| 工具名 | 功能 | 对应指令 | 触发示例 |
| :--- | :--- | :--- | :--- |
| `get_weather` | 查询当前天气/多日预报 | `/天气` | "北京天气怎么样" |
| `compare_weather` | 多城市天气对比 | — | "北京和上海哪个热" |
| `get_hourly_forecast` | 逐小时天气预报 | — | "今天下午会下雨吗" |
| `get_sunrise_sunset` | 日出日落月相 | — | "今天日出几点" |
| `subscribe_weather_alert` | 订阅灾害天气预警 | `/天气订阅` | "帮我订阅北京天气预警" |
| `unsubscribe_weather_alert` | 取消灾害天气订阅 | `/天气退订` | "取消上海的天气预警" |
| `list_weather_alerts` | 查看订阅城市列表 | `/预警列表` | "我订阅了哪些城市" |
| `check_weather_alerts` | 立即检查灾害预警 | `/检查预警` | "看看有没有灾害天气" |

## 🚨 灾害预警推送

### 工作原理

```
1. 用户通过 /天气订阅 <城市> 订阅
   → 订阅列表存入 KV 存储（持久化）

2. Cron 定时任务每 2 小时自动检查
   → 并发拉取所有订阅城市的天气数据
   → 检测 9 种灾害类型
   → 发现灾害 → 自动推送到订阅会话/群

3. 用户也可通过 /检查预警 立即检查
```

### 检测的灾害类型

| 灾害类型 | 检测条件 | 等级 |
| :--- | :--- | :--- |
| 🌧️ 暴雨 | weatherCode 为大雨/暴雨代码 | 警告/危险 |
| ⛈️ 雷暴 | weatherCode 为雷暴代码 | 警告/危险 |
| ❄️ 暴雪 | weatherCode 为大雪/暴雪代码 | 警告/危险 |
| 🧊 冻雨 | weatherCode 为冻雨代码 | 危险 |
| 🔥 极端高温 | 温度 ≥ 38°C（≥40°C 为危险） | 警告/危险 |
| 🥶 极端低温 | 温度 ≤ -10°C（≤-20°C 为危险） | 警告/危险 |
| 💨 大风 | 风速 ≥ 62km/h（≥88km/h 为危险） | 警告/危险 |
| 🌫️ 大雾 | 能见度 ≤ 1km（≤0.5km 为危险） | 警告/危险 |
| ☀️ 强紫外线 | UV ≥ 10 | 警告 |

### 预警等级

| 等级 | Emoji | 说明 |
| :--- | :--- | :--- |
| 🔴 紧急 | danger | 极端灾害，需立即采取行动 |
| 🟠 警告 | warn | 较强灾害，需注意防范 |
| 🟡 关注 | info | 一般提醒（如高降雨概率） |

### 推送去重

- 同一城市同一小时内不会重复推送
- 推送记录保留 7 天后自动清理
- 每条推送之间间隔 2 秒，避免触发平台风控

### 使用示例

```

     🔴 【紧急】深圳 天气预警
     ...
```

## ⚙️ 插件配置

在 AstrBot WebUI 的插件配置页面可以设置：

| 配置项 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `alert_check_interval` | 预警检查周期（cron 表达式） | `0 */2 * * *`（每2小时） |
| `alert_min_level` | 推送的最低预警等级 | `warn`（警告及以上） |

### 自定义检查频率示例

| cron 表达式 | 含义 |
| :--- | :--- |
| `0 */2 * * *` | 每 2 小时（默认） |
| `0 */1 * * *` | 每 1 小时 |
| `0 8,12,18 * * *` | 每天 8/12/18 点 |
| `0 */6 * * *` | 每 6 小时 |

## 🔧 技术细节

### 数据源

- **API**: [wttr.in](https://wttr.in) — 免费、无需 API Key 的天气服务
- **数据格式**: JSON (`format=j1`)
- **语言**: `lang=zh-cn`（中文天气描述）
- **覆盖范围**: 全球

### 架构

```
用户消息
  ├── /天气 指令 → weather_command() → 直接返回天气文本
  ├── /天气订阅 → 订阅管理 → KV 存储订阅列表
  ├── /检查预警 → 立即检查 → 灾害检测 → 返回结果
  ├── 自然语言提问 → LLM Tool Calling → 8 个工具 → AI 总结回复
  └── Cron 定时任务 → _cron_check_alerts()
                       → 拉取所有订阅城市天气（并发）
                       → 灾害检测（9 种类型）
                       → 发现灾害 → send_message() 推送到群
                       → 去重记录 → KV 存储
```

### LLM Tool 参数

#### get_weather
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `location` | string | 城市名称 |
| `include_forecast` | bool | 是否包含 3 天预报 |

#### compare_weather
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `locations` | list[string] | 2-5 个城市名称 |

#### get_hourly_forecast
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `location` | string | 城市名称 |
| `day` | string | `today` / `tomorrow` / `day_after_tomorrow` |

#### get_sunrise_sunset
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `location` | string | 城市名称 |

#### subscribe_weather_alert
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `location` | string | 要订阅的城市名称 |

#### unsubscribe_weather_alert
| 参数 | 类型 | 说明 |
| :--- | :--- | :--- |
| `location` | string | 要取消的城市名称，传 "全部" 取消所有 |

#### list_weather_alerts
（无参数）

#### check_weather_alerts
（无参数，检查当前会话所有订阅城市）

## 📝 开发说明

### 本地调试

1. 克隆 AstrBot 主仓库和本插件到 `AstrBot/data/plugins/` 目录下
2. 启动 AstrBot
3. 修改代码后在 WebUI 插件管理页面点击「重载插件」

### 代码规范

- 使用 `aiohttp` 异步网络请求（遵循 AstrBot 开发规范）
- 使用 `ruff` 格式化代码
- 类型注解完整
- 错误处理完善，不会因单个错误导致崩溃
- 多城市并发查询使用 `asyncio.gather`
- KV 存储持久化订阅和推送记录
